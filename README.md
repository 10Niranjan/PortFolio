# Niranjan Patil — Portfolio

Personal portfolio website built with **React + Vite**, deployed via **GitHub Pages**.

🔗 **Live site:** [10niranjan.github.io/portfolio](https://10niranjan.github.io/portfolio)  
📁 **Repo:** [github.com/10Niranjan/portfolio](https://github.com/10Niranjan/portfolio)

## Tech Stack

- **React 18** — UI framework
- **Vite** — build tooling & dev server
- **Vanilla CSS** — custom design system
- **GitHub Actions** — CI/CD deploy pipeline to GitHub Pages

## Getting Started

```bash
npm install
npm run dev
```

## Deployment

Pushes to `main` automatically trigger the GitHub Actions workflow (`.github/workflows/deploy.yml`), which builds and deploys to GitHub Pages.
