## Getting Started

```bash
git clone https://github.com/10Niranjan/portfolio.git
cd portfolio
npm install
npm run dev
```

## Deployment

Pushes to `main` automatically trigger the GitHub Actions workflow (`.github/workflows/deploy.yml`), which builds and deploys to **GitHub Pages**.
